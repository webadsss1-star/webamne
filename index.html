Tipos de cliente

Avançado oferece recursos completos de colaboração web e funciona melhor em navegadores recentes e conexões rápidas.

Padrão é recomendado para conexões lentas, navegadores antigos ou acessibilidade facilitada.

Móvel é recomendado para dispositivos móveis.

Touch é recomendado para tablets.

Para definir o cliente padrão, altere as opções de login nas preferências após entrar.
